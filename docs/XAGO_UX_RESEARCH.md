# XAGO UX Research — публичная часть и сценарий авторизации

Дата: 18.11.2026  
Метод: Playwright Chromium, отдельный persistent-профиль `data/xago_profile`, только публичные страницы.  
Ограничения: не копировались JS/CSS/графика, не выполнялись оплаты, отклики, изменение настроек и извлечение приватных данных.  
Приватный кабинет: интерактивный вход запускается `py -3 tools/xago_research.py --login`; пользователь вводит Telegram/код **только в браузере**. Скрипт не читает токен, не отправляет его в LLM и сохраняет лишь локальную сессию Chromium.

## 2. Авторизация

Публичная страница предлагает два пути:

1. **Telegram** — кнопка открывает `@xagoru_bot`; после подтверждения пользователь возвращается на сайт.
2. **Код** — пользователь отправляет `/token` боту и вводит полученный код в поле на сайте.

Требуется согласие с условиями, политикой и обработкой данных.  
Для исследования создан отдельный сценарий, который:

- открывает видимый Chromium с отдельным профилем;
- не читает и не логирует токен;
- ждёт появления авторизованного интерфейса;
- после входа собирает **структуру** разделов (заголовки, кнопки, URL), маскируя header/account в скриншотах;
- не нажимает оплату, отклики, удаление и не меняет настройки.

## 3. Публично подтверждённые функции XAGO

| Функция | Как подаётся | UX-решение |
|---|---|---|
| Автоотклики hh.ru | 100/сутки Free, 200 PRO | сильное обещание + честная оговорка «лимит hh не обходим» |
| Поиск и фильтры | запрос, зарплата, опыт, формат, регион, стоп-слова, чёрный список компаний | фильтры привязаны к резюме/аккаунту |
| ИИ-письма | под каждую вакансию, свой промпт, язык | анти-галлюцинации, отказ от «я не подхожу» |
| Вопросы/тесты | ответы нейросетью | снижает пропуск вакансий с анкетами |
| Чаты HR | 3 режима, черновики/автопилот | явный контроль автоматизации |
| Календарь интервью | согласование времени, бриф | снижает ручную переписку |
| Автоподнятие резюме | каждые 4 часа | отдельная ценность вне откликов |
| Аналитика рынка | медианы, регионы, навыки | полезный контент до регистрации |
| Тарифы | Free без срока, PRO 299 ₽ | низкий порог входа, прозрачные лимиты |
| Безопасность | серверы РФ, данные/сессии | доверие и снятие страха |

## 4. UX-паттерны, которые стоит перенять

1. **Обещание + ограничение рядом.** «100 откликов» и «лимит hh не обходим» снижают недоверие.
2. **Один вход через Telegram** и резервный код — меньше трения, чем пароль.
3. **Пошаговый чек-лист запуска** на главной и в кабинете.
4. **Разделение свободы автоматизации**: не трогать / черновики / автопилот.
5. **Прозрачные причины**: почему вакансия пропущена, почему письмо не отправлено.
6. **Много контекстных FAQ** рядом с функциями, а не отдельная энциклопедия.
7. **Публичная аналитика рынка** как бесплатный магнит.
8. **Явные лимиты и цена** без скрытых условий.
9. **Кабинет как рабочий процесс**: подключение → поиск → отклики → чаты → интервью.
10. **Уведомления в Telegram** как канал состояния, а не спам.

## 5. Замеченные недостатки / риски

- Главная перегружена обещаниями и социальными докиванельствами; важные ограничения спрятаны ниже.
- Много цен и лимитов в разных местах; пользователю трудно сравнить Free/PRO.
- Автопилот чатов требует очень ясного аудита действий; иначе доверие падает.
- Нет видимой демонстрации «до/после» письма на публичной части.
- Термины «бот», «автопилот», «ИИ-письмо» смешиваются; нужна единая модель.
- Публичный экран входа не объясняет, что произойдёт после Telegram, до нажатия.
- Мобильная плотность таблиц на `/rynok/` и `/sravnenie/` высокая.

## 6. Матрица сравнения с AI Job Hunter

| Возможность | XAGO (публично) | AI Job Hunter 2.0 | Решение для 3.0 |
|---|---|---|---|
| Источники | hh.ru | «Работа России», hh API, фиды, импорт | сохранить; добавить интерфейс discover/fetch |
| Автоотправка | да, hh | только ручная/разрешённая | не включать по умолчанию; оставить контроль |
| Скоринг | подбор по фильтрам | 8 факторов + eligibility | разделить eligibility/skill/career/utility |
| Объяснение | частично | топ-3 фактора | усилить: причины, пробелы, уверенность |
| Резюме | версии под вакансию | Resume Studio + DOCX/PDF | добавить историю версий и предпросмотр под вакансию |
| Письма | ИИ под вакансию | AITUNNEL + факт-чек | сохранить; GLM как основной, DeepSeek резерв |
| Чаты HR | автопилот/черновики | импорт + черновики | не включать автопилот без разрешения |
| Аналитика | рынок + отклики | воронка, источники, posterior | добавить AI-стоимость, события, причины пропуска |
| Онбординг | Telegram + чек-лист | PDF/DOCX + подтверждение фактов | сохранить мастер, добавить Qwen + fallback |
| Мобильность | адаптивная | адаптивная | сохранить, добавить тёмную тему |
| Доверие | серверы РФ, лимиты | локально, без выгрузки сессий | подчёркивать локальность и аудит |

## 7. Приоритеты реализации

1. **P0:** исправление Qwen (thinking/empty content, таймаут, fallback AITUNNEL, статус/отмена).
2. **P0:** разделение скоринга и жёсткая блокировка Senior/Lead без опыта.
3. **P0:** Job Explorer с фильтрами, избранным и причинами.
4. **P1:** новый dashboard: статус агента, последнее обновление, AI-расход, воронка, события, причины пропуска.
5. **P1:** Resume Studio: история версий, предпросмотр под вакансию, подтверждение фактов.
6. **P1:** очередь: версия резюме, повторная проверка фактов, ошибки.
7. **P2:** тёмная тема, микровзаимодействия, улучшение мобильной плотности.
8. **P2:** расширение источников (Хабр Карьера, SuperJob) только после проверки правил.

## 8. Что не копируется

- Закрытый серверный код, приватные API, токены, чужие тексты и графика.
- Массовые CSS/JS-файлы.
- Автоматические отклики/покупки при исследовании.
- Персональные данные аккаунта в скриншотах/отчётах.

## 9. Приватный кабинет (после локального входа)

Вход выполнен пользователем в отдельном Chromium; токен не читался и не сохранялся
скриптом. Собрана только структура (заголовки, кнопки, маршруты), без скриншотов
личных данных и без изменения настроек: `xago-private-structure.json`.

|---|---|---|
| Дашборд | `/dashboard` | «Отклики остановлены», «Последний прогон», «Работодатели ждут ответа», кнопки «Запустить», «Автозапуск», «Пауза», «Вернуть в очередь», «Пройтись по чату PRO», «По избранному» |
| Аккаунты | `/accounts` | карточки аккаунтов, «Исключён Junior Data Scientist / Стажёр ML», «В выдаче 71, новых 2, за сутки», «Снять лимит», drag-order, «Добавить ещё аккаунт» |

Что подтвердилось в кабинете:

- Главный экран — не маркетинг, а пульт: статус остановки, последний прогон,
  очередь чатов, быстрый запуск.
- Аккаунты и резюме — отдельные сущности; по аккаунту видны новые вакансии и
  исключения.
- Чаты — центр работы: «нужен ответ», «бот разобрал», поиск, выгрузка.
- Настройки откликов и Telegram-уведомления вынесены отдельно.
- PRO-статус истёк; интерфейс мягко предлагает покупку, не блокируя Free.
- Тёмная тема доступна прямо в сайдбаре.

Приватные скриншоты не сохранены: в них мог быть аккаунт/ID. Оставлена только
обезличенная структура; PII заменён на `[скрыто]`.
