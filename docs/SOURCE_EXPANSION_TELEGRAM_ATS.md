# Telegram, ATS и новые карьерные источники

## Telegram (публичный режим)

`core/sources/telegram_public.py` читает только `https://t.me/s/<channel>`:
текст, ссылки, дату и ID сообщения. Авторизация, Telethon, вступление в каналы и
отправка сообщений не используются.

- 11 проверенных каналов: `it_interns`, `young_june`, `it_vakansii_jobs`,
  `pythonpythonjobs`, `job_python`, `datasciencejobs`, `data_vacancy`,
  `offersanalysis`, `hcareers_jobs`, `de_rabota`, `data_engineer_jobs`.
- Подборки разбиваются на отдельные вакансии только по строкам, похожим на
  должность; обязанности, требования, реклама курсов и статьи отбрасываются.
- Одиночные посты сохраняют ссылку на оригинальный пост; если есть внешняя
  ссылка на вакансию, она используется как ссылка для отклика.
- Инкрементально: `telegram_channels.last_message_id`; повторный запуск не
  перечитывает старые сообщения и не создаёт дубли.
- Прокси: `TELEGRAM_PROXY` / `HTTPS_PROXY` или системный proxy Windows.

Управление каналами: «Настройки → Поиск и источники → Telegram-каналы» —
добавить URL/@channel, выключить, удалить, обновить, посмотреть посты/вакансии/
попадание в каталог и сколько прошло фильтр.

## ATS

`core/sources/ats.py` поддерживает публичные job boards:

- Greenhouse `boards-api.greenhouse.io`;
- Ashby `api.ashbyhq.com/posting-api/job-board`;
- Lever `api.lever.co/v0/postings` (адаптер готов, конкретные board-токены
  добавляются в настройках).

Список компаний задаётся в `sources.ats.boards`; фильтр по должности/департаменту
и лимит на board. Greenhouse-описание догружается через detail endpoint, Ashby
отдаёт `descriptionHtml` сразу. Никакие закрытые/платные API не используются.

## Карьерные сайты

- **Т-Банк** (`tbank`): публичная страница IT-вакансий, карточки и текст
  «Описание/Обязанности/Требования».
- **МТС** (`mts`): публичный поиск и Nuxt-описание (добавлен ранее в этой ветке).

Sber, Яндекс, Ozon Tech, Авито, Альфа-Банк, ВТБ, X5, Wildberries, Kaspersky и
др. не подключены: для них не найден стабильный публичный структурированный
интерфейс в рамках этой итерации. Это отображается как отсутствие источника, а
не как «работает».

## Единый каталог

Все новые вакансии проходят существующие `upsert_job` → дедупликацию →
`rank_pending` → STRONG / OPPORTUNITY / REJECTED → shortlist. Дубли сохраняются
как публикации (`job_publications`), оригинальные ссылки остаются доступны.
Иностранные remote-вакансии (US/Canada/Europe и т.п.) не считаются STRONG для
кандидата в Москве: они переводятся в review/opportunity, если нет
worldwide/global-условий.

## Discovery кандидатов

`core/sources/telegram_discovery.py` читает публичные каталоги:

- gist lovach (CSV ~176 каналов);
- firstmessage.ru;
- telemetr.me (видимая часть каталога);
- GitHub Ebazhanov/it-vacancies;
- CSV, вставленный/загруженный пользователем.

Каналы попадают только в `telegram_candidates` со статусом `discovered`.
Проверка читает последние публичные посты и считает публикации за 30 дней,
реальные вакансии, стажировки, junior-позиции, рекламу, свежесть и quality.
Затем статус становится `qualified`, `irrelevant`, `unavailable` или
`inactive`. Включение — только вручную (`enabled`). Повторный discovery не
создаёт дублей.

## Обогащение ссылок

`core/sources/job_enrichment.py` извлекает ссылки из конкретного Telegram-поста,
классифицирует hh.ru / Хабр Карьеру / ATS / агрегаторы / страницы вакансий,
делает максимум 1–2 перехода и загружает страницу через `core/safe_http.py`.
Приоритет: JSON-LD `JobPosting`, затем основной текст страницы. Для подборок
используется ссылка конкретной вакансии, а не первая ссылка дайджеста.

Сохраняется provenance в `detail.enrichment`: URL, тип ссылки, поля, missing
fields, время. Пустые значения не выдумываются. Ручное действие «Обновить
подробности» доступно в карточке; автоматически обогащается до 8 Telegram-вакансий
за цикл (`sources.telegram.enrich_limit`).

`core/safe_http.py` разрешает только HTTP/HTTPS, проверяет DNS и каждый redirect,
блокирует loopback/private/link-local/metadata IP, ограничивает размер и время,
запрещает cookies и небезопасные content-type.

## Ограничения


- Публичные Telegram-превью могут менять разметку; при ошибке канал получает
  статус `error`, а не фиктивные вакансии.
- Telethon-режим не подключён: публичного режима достаточно, ключи Telegram API
  не требуются. Для приватных каналов потребуется отдельная авторизация.
- ATS-вакансии часто требуют права работы в стране; это отражается в локации и
  категории, а не маскируется.
- Реальные отклики не отправляются; браузерный adapter работает в `draft_only`.
